# PHOTH Studio

브라우저 안에서만 동작하는 사진 색감 보정 · 인물 리터칭 스튜디오.
설치 없이 열면 바로 쓰고, 서버도, 업로드도, 회원가입도 없습니다.

**라이브:** https://starha2015-svg.github.io/photh-studio/

## 무엇을 할 수 있나

- **프리셋 14종** — 코닥 포트라, 후지 청량, 웨딩 소프트, 데이트 웜톤, 무드 다크, 파스텔, 빈티지 90s, 모노크롬, 하이키, 시네마틱, 골든아워, 쿨톤, 클래식 그레인 + 강도 0~100%
- **세부 보정** — 노출 · 대비 · 하이라이트 · 그림자 · 색온도 · 틴트 · 채도 · 선명도 · 비네팅 · 필름 그레인
- **인물 리터칭** — 피부 매끈(에지 보존 스무딩) · 피부 톤 업 · 배경 보케(흐림) + 빛망울. 눈·입술·머리카락은 보호됩니다.
- **레퍼런스 색감 따라하기** — 마음에 드는 사진을 올리면 CIE Lab(Renhhard color transfer)으로 톤·색감·명암을 옮깁니다. 강도 조절 + 전체 사진 일괄 적용.
- **전/후 비교** — 드래그 슬라이더, 원본 보기, 확대/맞춤
- **내보내기** — 원본 해상도 JPG/PNG, 전체 ZIP. 저장 파일에는 워터마크나 별도 표시가 들어가지 않습니다.

## 처리 방식

모든 계산은 방문자의 브라우저에서만 일어납니다.

| 단계 | 구현 |
| --- | --- |
| 색감 그레이딩 | WebGL2 프래그먼트 셰이더 (톤 커브, 스플릿 토닝, 비네팅, 그레인) |
| 인물 마스크 | MediaPipe `@mediapipe/tasks-vision` — Image Segmenter(selfie_multiclass) + Face Landmarker |
| 피부 스무딩 | 마스크 가중 양방향(에지 보존) 샘플링 |
| 배경 보케 | 축소·가우시안 배경 + 하이라이트 추출 글로우(빛망울) 합성 |
| 레퍼런스 매칭 | Reinhard Lab 색 분포 전이 (평균·표준편차 매칭) |

CDN이 막히거나 모델 로드에 실패해도 피부톤 기반 마스크로 자동 폴백해 편집은 계속됩니다.

## 구조

```
index.html
css/style.css
js/app.js      화면 상태 · UI 배선
js/gl.js       WebGL2 렌더 파이프라인 (리터칭 → 보케 → 매칭 → 그레이딩)
js/presets.js  프리셋 정의
js/color.js    Lab 변환 · 색 통계 · 보정량 추정
js/bokeh.js    배경 흐림 · 빛망울 텍스처 생성
js/ai.js       MediaPipe 인물/피부 마스크 + 폴백
assets/        샘플 사진(PHOTH @ph_ot_h 포트폴리오 3장), 아이콘, 공유 이미지
```
