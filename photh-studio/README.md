# PHOTH Studio

브라우저 안에서만 동작하는 사진 색감 보정 · 인물 리터칭 스튜디오.
설치 없이 열면 바로 쓰고, 서버도, 업로드도, 회원가입도 없습니다.

**라이브:** https://starha2015-svg.github.io/photh-studio/ (비공개 · 비밀번호 잠금)

## 무엇을 할 수 있나

- **프리셋 14종** — 코닥 포트라, 후지 청량, 웨딩 소프트, 데이트 웜톤, 무드 다크, 파스텔, 빈티지 90s, 모노크롬, 하이키, 시네마틱, 골든아워, 쿨톤, 클래식 그레인 + 강도 0~100%
- **세부 보정** — 노출 · 대비 · 하이라이트 · 그림자 · 색온도 · 틴트 · 채도 · 선명도 · 비네팅 · 필름 그레인
- **HSL 8색상** — 빨강·주황·노랑·초록·아쿠아·파랑·보라·마젠타의 색조/채도/휘도
- **수평·기울기** — Sobel 엣지 방향 히스토그램 기반 자동 수평(±15°), 얼굴 눈높이 보조, 모서리 빈 곳 없는 자동 크롭 확대
- **인물 리터칭** — 피부 매끈 · 톤업 · 잡티/주름(주파수 분리) · 다크서클 · 유분기 / 눈 밝기·선명 · 캐치라이트 · 치아 미백 / 립 틴트 · 블러셔 · 헤어 윤기
- **얼굴형** — 갸름 · 눈 크기 · 코 슬림 · 입꼬리 미소 (WebGL2 그리드 메쉬 워핑, 얼굴 밖 감쇠)
- **배경·조명** — 배경 보케·빛망울, 배경 밝기, 단색 배경 교체(화이트/그레이/다크/크림/블루), 가상 햇빛(방향 패드 · 강도 · 색감 5500~3200K · 역광 번짐 · 림라이트)
- **레퍼런스 색감** — 마음에 드는 사진의 톤을 Reinhard Lab 색 분포 전이로 옮기고, `내 레퍼런스`로 저장해 다음 방문에도 카드 한 번으로 적용
- **전/후 비교** · 원본 해상도 JPG/PNG · 전체 ZIP 저장 (워터마크 없음)

## 처리 방식

모든 계산은 방문자의 브라우저에서만 일어납니다. 사진은 어떤 서버로도 전송되지 않습니다.

| 단계 | 구현 |
| --- | --- |
| 색감 그레이딩 | WebGL2 프래그먼트 셰이더 (톤 커브, 스플릿 토닝, HSL, 비네팅, 그레인) |
| 인물 마스크 | MediaPipe `@mediapipe/tasks-vision` — Image Segmenter(selfie_multiclass) + Face Landmarker |
| 부위 마스크 | 얼굴 랜드마크로 눈·입술·치아·볼·눈밑·캐치라이트, 세그멘터 헤어 채널로 헤어 |
| 피부 스무딩 | 마스크 가중 양방향(에지 보존) 샘플링 + 주파수 분리 |
| 햇빛 | 휘도·얼굴 높이장 기반 2.5D 법선 → 방향광·소프트 섀도우·림라이트·글로우 |
| 얼굴형 | 랜드마크 기반 변위 맵 → 48×48 그리드 메쉬 정점 변형 |
| 레퍼런스 매칭 | Reinhard Lab 색 분포 전이 (평균·표준편차 매칭) |

CDN이 막히거나 모델 로드에 실패해도 피부톤 기반 마스크로 자동 폴백해 편집은 계속됩니다.

## 구조

```
index.html
css/style.css
js/lock.js     비밀번호 잠금(SHA-256 해시 비교) · 인증 후 app.js 로드
js/app.js      화면 상태 · UI 배선
js/gl.js       WebGL2 렌더 파이프라인 (리터칭 → 보케 → 햇빛 → 매칭 → 그레이딩·워핑)
js/presets.js  프리셋 정의
js/color.js    Lab 변환 · 색 통계 · 보정량 추정
js/bokeh.js    배경 흐림 · 빛망울 텍스처 생성
js/ai.js       MediaPipe 인물/피부/부위 마스크 · 얼굴 높이장 + 폴백
js/level.js    자동 수평 (엣지 방향 히스토그램 · 눈높이 보조)
assets/        아이콘, 공유 이미지
```
