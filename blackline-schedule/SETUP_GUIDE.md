## 1. 팀원 사용법

1. `https://starha2015-svg.github.io/blackline-schedule/` 접속
2. 팀 공용 비밀번호 입력 → **확인**
3. “이 기기에서 로그인 유지”를 체크하면 7일간 다시 묻지 않습니다.
4. 이후 10초마다 자동으로 서버와 맞춰지고, 화면으로 돌아올 때도 갱신됩니다.
   상단 배지에 마지막 동기화 시각이 보이고, **새로고침**으로 즉시 맞출 수 있습니다.
5. 공용 PC에서 쓰셨다면 **잠금** 버튼을 누르세요(토큰이 즉시 삭제됩니다).

### 여러 날(기간) 일정
- 일정 등록·수정 창의 **시작일 / 종료일** 두 칸으로 기간을 정합니다. 종료일을 비우거나 시작일과 같게 두면 하루 일정입니다.
- 시작일을 먼저 고르면 종료일이 시작일로 자동으로 맞춰지고, 이어서 종료일만 바꾸면 됩니다.
- 달력에서는 기간 일정이 **칸 경계를 가로지르는 한 줄 막대**로 보입니다. 구글·네이버 캘린더처럼 주(7일) 단위로 막대가 이어지고, 제목은 매일 반복되지 않고 막대 왼쪽에 한 번만 나옵니다. 예: `11/23~27 정부행사(2, 제우스)`가 23~27일 다섯 칸을 하나의 검은 막대로 쭉 지나갑니다(입금 완료는 초록색).
- 주를 넘어가는 일정(예: 11/26 목 ~ 11/29 일)은 그 주 목~토 3칸짜리 막대 하나, 다음 주 일요일 1칸짜리 `↳ 제목` 막대 하나로 자연스럽게 이어집니다. 막대를 누르면 그 주 시작 칸의 날짜가 선택되고 일정 상세(수정) 창이 열립니다.
- 인원별 근무표와 인원 집계의 근무일수·총시간은 기간의 **매일**을 반영합니다. 상단 월간 통계와 미수금 탭은 행사 **1건당 한 번**만 집계합니다.
- 엑셀 내보내기에 **종료일**·**기간(일)** 열이 추가되었습니다.

## 3. 팀 공용 비밀번호 바꾸는 방법

1. https://dash.cloudflare.com 로그인 → 왼쪽 **Workers & Pages**
2. **blackline-api** 선택 → **Settings** 탭
3. **Variables and Secrets** 에서 `TEAM_PASSWORD` 오른쪽 **Edit**(연필)
4. 새 비밀번호 입력 → **Encrypt**(Secret 유지) → **Save**
5. 상단/오른쪽 **Deploy** 를 눌러 반영 (이 단계를 빼면 적용되지 않습니다)
6. 팀원에게 새 비밀번호를 알리고, 각자 다시 로그인하게 하세요.

> 비밀번호 규칙은 없습니다(대소문자 구분). 현재는 요청대로 `0129` 네 자리로 맞춰 두었는데, 주소가 공개되어 있으니 외부인이 짐작하기 쉬운 편입니다. 나중에 팀이 외우기 쉬우면서 짐작하기 어려운 10자 이상으로 바꾸시는 것을 권합니다. 비밀번호를 바꾸면 이미 로그인한 기기는 그대로 쓰이고(7일 토큰), 새로 로그인하는 사람만 새 비밀번호를 넣으면 됩니다.

## 5. 서버 코드를 고칠 때 (나중에 기능 추가)

1. 이 폴더의 `cloudflare-worker.js` 를 수정합니다.
2. 대시보드 → Workers & Pages → blackline-api → **Edit code** → 전체 선택 후 붙여넣기 → **Deploy**
   또는 이 폴더에서 `python3 deploy.py` 실행(계정 키가 `.secrets/` 에 있을 때).
3. 화면(`index.html`)을 고치면 `starha2015-svg.github.io` 리포의 `blackline-schedule/index.html` 로 복사해 commit·push 하면 1~2분 뒤 반영됩니다.

`schema.sql` 은 표 구조입니다. 이미 적용되어 있고, 다시 실행해도 안전합니다.
D1 Console(대시보드 → Storage & Databases → D1 → blackline-db → Console)에서 직접 확인·수정도 가능합니다.

## 7. 무료 한도 (지금 사용량 기준)

- Worker: 하루 100,000 요청. 10초 자동 동기화는 탭을 켜둔 1인당 하루 약 8,600회 → 5명이 계속 켜둬도 4만 회대입니다.
  요청이 걱정되면 `index.html` 의 `SYNC_MS = 10000` 을 `30000`(30초)으로 바꾸면 3분의 1로 줄어듭니다.

## 8. 문제 해결

| 증상 | 원인·해결 |
|---|---|
| “서버에 연결하지 못했습니다” | 인터넷/Worker 상태 확인. `https://blackline-api.starha2015.workers.dev/api` 가 `{"ok":true...}` 를 주는지 확인 |
| “비밀번호가 맞지 않습니다” | 대시보드의 `TEAM_PASSWORD` 값과 비교(대소문자 구분) |
| “시도가 너무 많습니다. 1분 뒤에…” | 같은 IP에서 1분에 8회 넘게 틀림 → 1분 대기 |
| “세션이 만료되었습니다” | 토큰 7일 만료 → 다시 로그인 |
| 저장했는데 다른 사람에게 늦게 보임 | 최대 10초. **새로고침**으로 즉시 확인 |
| 브라우저 콘솔 CORS 오류 | `ALLOWED_ORIGIN` 이 `https://starha2015-svg.github.io` 인지 확인 |

## 9. 보안 메모

- 사이트는 공개 주소지만 **일정 데이터는 토큰 없이는 절대 내려가지 않습니다**(모든 일정 API 401 검사).
- 비밀번호는 Cloudflare Secret에만 저장되고, 로그인 시 SHA-256 상수시간 비교를 합니다.
- 토큰은 HMAC-SHA256 서명 + 7일 만료. 브라우저 sessionStorage(탭 닫으면 삭제), “로그인 유지” 시 localStorage.
- 로그인 시도는 IP당 분당 8회로 제한됩니다.
- 사이트 소스는 공개(GitHub Pages)이지만 Worker 코드·비밀번호·데이터는 공개되지 않습니다.
